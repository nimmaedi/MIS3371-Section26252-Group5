Employee Shift-Swap System

Submit a request to exchange your scheduled shift with another eligible employee.

Before You Submit a Shift-Swap Request

Enter both employees’ IDs and the start and end date and time for each scheduled shift. All fields are required. The request will be sent to the receiving employee and, when required, a manager for review.
